# 피벗 설계 — 50대 한국 아저씨 MMORPG

> 펭귄 호텔(경영 시뮬) → 브라우저 2D 탑다운 MMORPG. 레퍼런스: playfeiven.com, 리니지 계열.

## 1. 타겟 페르소나

- **50대 한국 남성.** 90년대 말~2000년대 초 PC방에서 리니지·바람의나라·뮤를 했던 세대.
- 지금은 퇴근 후나 주말에 **폰·PC로 틈틈이** 해요. 오래 붙잡고 있기는 어렵지만 **꾸준히 접속**해요.
- 지갑은 열려 있어요. 대신 **"내가 이 서버에서 누구냐"** 가 보여야 돈과 시간을 써요.
- 노안 → 작은 글씨와 복잡한 조작을 싫어해요.

**설계 원칙:** "그때 그 감성 + 지금의 편의성". 조작은 쉽게, 과시는 크게, 소속감은 진하게.

## 2. 때려넣을 요소 전부

### A. 향수 (그때 그 감성)
| 요소 | 내용 |
|---|---|
| 정통 판타지 세계관 | 기사·요정(활)·마법사·다크엘프 계열 직업, 성·마을·던전 |
| 픽셀/도트풍 2D 탑다운 | 리니지 초창기 화면 비율과 색감 |
| 상징적 사운드 | 레벨업 "띠링", 강화 성공/실패 효과음, 마을 BGM |
| 화폐 이름 | "아데나" 느낌의 고유 화폐(가칭 **금화/베리**) |
| 귀환 주문서·순간이동 주문서 | 옛날 소모품 그대로 |
| 변신 | 몬스터 변신 카드 (이동속도·외형 과시) |

### B. 과시와 서열 (내가 누군지)
| 요소 | 내용 |
|---|---|
| **강화** | +0~+15. +7부터 실패 시 증발(파괴). 성공 시 **서버 전체 공지** "○○님이 +9 진명황의 집행검 강화에 성공!" |
| 등급·티어 | 일반 < 희귀 < 영웅 < 전설 < 신화. 이름 색으로 한눈에 |
| 랭킹 | 레벨·전투력·재산·PK 랭킹. 서버 1위 칭호와 전용 이펙트 |
| 칭호 | "태초의 학살자", "강화의 신" 등 업적 칭호를 이름 위에 표시 |
| 외형 | 무기 강화 단계별 빛 이펙트(+7 파랑, +9 보라, +11 금빛) |
| 성주 | 성을 먹은 혈맹 군주에게 왕관·세금 수입·전용 망토 |

### C. 소속감 (형님 동생)
| 요소 | 내용 |
|---|---|
| **혈맹** | 군주·부군주·수호기사 직위, 혈맹 마크, 혈맹 창고, 혈맹 채팅 |
| **공성전** | 주 1회 정해진 시간. 혈맹 단위로 성 점령 → 세금·버프 |
| 보스 레이드 | 정해진 시간 필드보스 등장 → "자리 차서 보스나 잡아야지" |
| 파티 | 경험치·드롭 분배, 파티 구인 게시판 |
| 채팅 | 전체·파티·혈맹·귓속말·외치기(확성기 아이템) |

### D. 경쟁 (적이 있어야 재미있다)
| 요소 | 내용 |
|---|---|
| **PK** | 필드 PvP 허용. 선공 시 보라돌이 → 카오틱(빨간 이름), 사망 시 장비 드롭 위험 |
| 성향치 | 라우풀/카오틱. 카오는 마을 경비병이 공격 |
| 원수 목록 | 나를 죽인 사람 자동 등록, 접속 알림 |
| 사냥터 쟁 | 좋은 자리는 한정. 혈맹끼리 자리싸움 |

### E. 편의성 (시간이 없다)
| 요소 | 내용 |
|---|---|
| **자동사냥** | 사냥터 지정 → 자동 이동·공격·물약 사용. 핵심 |
| 오프라인 보상 | 접속 안 한 동안 쌓인 경험치·금화 수령 |
| 자동 퀘스트 | 퀘스트 클릭 시 자동 길찾기 |
| 큰 글씨 모드 | UI 배율 100/125/150%, 기본 125% |
| 원터치 | 물약 자동 사용 HP % 설정, 스킬 자동 시전 |
| 모바일 대응 | 세로·가로 터치 조작 (가상 조이스틱) |

### F. 경제 (돈 버는 맛)
| 요소 | 내용 |
|---|---|
| 거래소 | 유저 간 경매. 수수료 8%, 등급·티어·강화 필터, 시세 그래프 |
| 개인상점 | 마을에 좌판 깔기 (오프라인 판매) |
| 제작 | 재료 모아 장비 제작 |
| 드롭 | 희귀 아이템 드롭 시 서버 공지 |

### G. 매일 들어올 이유
- 출석부(7일·28일 보상), 일일·주간 퀘스트, 접속 시간 보상
- 요일 던전, 시간제 이벤트 사냥터
- 낚시(방치형 미니 콘텐츠)

## 3. 수익모델 가이드

- **월정액 패스**(자동사냥 시간 확대·창고 확장)와 **외형·편의 상품** 위주로 해요.
- 확률형 상품을 넣으면 **확률을 반드시 공개**해야 해요(게임산업법, 2024.3 시행). 표시 UI를 처음부터 만들어 둬요.
- 강화 확률도 게임 안에서 공개해요.

## 4. 기술 구성

| 영역 | 선택 | 비고 |
|---|---|---|
| 클라이언트 | Vite + TypeScript + PixiJS v8 | 기존 레포 재사용 |
| 시점 | 2D 탑다운 (타일맵) | 아이소 렌더는 폐기 |
| 서버 (2단계) | Node + Colyseus (WebSocket) | 방=맵/채널 |
| DB (2단계) | PostgreSQL | 계정·캐릭터·인벤·거래소 |
| 코어 로직 | 엔진 무관 TS (`src/core/`) | 클라·서버 공용. 서버 권위 구조로 확장 |

재사용: 빌드 설정, `contracts/`(IClock·IRandom), 루프 배선, HTML/CSS UI 패널 구조.
폐기/대체: 호텔 모델·시스템, 아이소 렌더러.

### 멀티플랫폼 전략 (웹 → 모바일·PC)

웹 코드 하나를 그대로 감싸서 배포해요. 엔진은 바꾸지 않아요.

| 플랫폼 | 방법 |
|---|---|
| 웹 | 그대로 배포 (PWA 설치 지원) |
| Android / iOS | Capacitor로 감싸서 스토어 출시 |
| PC (Windows/Mac) | Tauri(가벼움) 또는 Electron로 감싸서 설치판·Steam 출시 |

지금부터 지킬 규칙:
1. **입력 추상화:** 마우스·키보드·터치·가상 조이스틱을 `InputAction`(이동·공격·스킬1..4·물약)으로 통일. 게임 로직은 키 이름을 모름.
2. **반응형 UI:** 가로/세로, 폰~모니터 해상도 대응. UI 배율 설정. 버튼 최소 44px.
3. **플랫폼 API 격리:** 저장소·결제·푸시·공유는 `platform/` 인터페이스 뒤로. 웹/네이티브 구현을 갈아끼움.
4. **서버 권위:** 판정·드롭·강화는 서버가 결정. 어느 클라이언트든 동일하게 동작하고 핵 방지.
5. **성능 예산:** 저사양 안드로이드 기준 30fps. 스프라이트는 아틀라스로 묶고, 화면 밖 객체는 그리지 않음.
6. **결제 분리:** 스토어 앱은 인앱결제 규정을 따라야 해서 결제 모듈은 플랫폼별로 따로 구현.

## 5. 로드맵

### 1단계 — 싱글 프로토타입 (클라이언트만)
1. 탑다운 맵 + 캐릭터 이동(클릭/WASD) + 카메라
2. 몬스터 스폰·AI·전투·사망·드롭
3. HP/MP/EXP, 레벨업, 스킬 단축창(1~4), 물약(Q/E)
4. 인벤토리·장비 슬롯, 등급·티어
5. **강화 시스템** + 성공 공지 연출
6. **자동사냥** 토글
7. 퀘스트 추적 + 미니맵 + 큰 글씨 UI

### 2단계 — 멀티플레이
- Colyseus 서버, 계정, 같은 맵 동기화, 채팅, 파티, PK·성향치

### 3단계 — 사회·경제
- 혈맹, 거래소, 랭킹·칭호, 필드보스, 공성전

## 6. 미정 사항

- 게임 이름
- 아트 소스 (직접 도트 / 에셋 구매 / 생성)
