# DEAD GIVEAWAY (가제: LAST WORDS)

> **"Get murdered. Then snitch."**
> 살해당한 플레이어가 유령이 되어, 말 대신 물건으로 범인을 고발하는 4~8인 소셜 디덕션.

## 1. 한 문장 피치

마피아·어몽어스류는 **죽으면 끝**이다. 이 게임은 **죽어야 진짜 시작**이다.
유령은 말을 못 한다. 냉장고 자석, 김 서린 거울, 깜빡이는 전등, 액자를 밀어서 범인을 알려야 한다.
그리고 범인은 그 메시지를 **지우거나, 고쳐 써서 남에게 누명을 씌운다.**

## 3. 무대

**눈에 갇힌 산장의 주말 파티.** 전화선 끊김, 경찰은 새벽에 도착.
고전 추리물(아가사 크리스티) 세팅이라 설명이 필요 없고, 생활 소품이 많아 유령 장난감이 풍부하다.
추가 맵 후보: 크루즈 선상 디너, 대학 기숙사, 남극 연구기지.

## 4. 역할

### 손님 (산 자)
- 목표: 새벽(경찰 도착)까지 살아남고, 살인마를 **지하 와인 저장고에 가둔다.**
- 회의·투표 없음. 의심 가는 사람을 **직접 붙잡아 끌고 가서** 가둔다(물리). 무고한 사람을 가두면 그만큼 살인마에게 유리.
- 할 일: 발전기 연료 넣기, 벽난로 장작, 무전기 수리 → 살인마가 방해할 틈을 만든다.

### 살인마
- 목표: 새벽 전까지 산 자 수 ≤ 살인마 수.
- 공용 **레인코트·마스크**를 걸치고 범행 → 정체를 숨긴다.
- 유령 대응 도구 (아래 6절).

### 유령 (죽은 손님)
- 목표: 산 자 팀 승리. 개인 점수 = 범인을 정확히 고발했는가.
- **말 못 함.** 유령끼리는 대화 가능.
- 벽 통과, 비행. 산 자에게는 보이지 않음.

## 5. 핵심 메커닉: 유령 소통

### 5-1. 원한 게이지 (Poltergeist Energy)
- 사망 시 50%로 시작, 천천히 충전. 물건 크기만큼 소모.
- **자기 시체가 발견되면** 게이지 최대치 상승 → 산 자들이 시체를 찾을 이유.
- 새벽이 가까울수록 유령이 희미해짐 → 시간 압박.

### 5-2. 소통 도구 (맵에 배치)
| 도구 | 장소 | 특징 |
|---|---|---|
| 냉장고 자석 | 부엌 | 글자 하나씩 밀기. 느리지만 확실. **살인마가 몰래 고칠 수 있음** |
| 김 서린 거울 | 욕실 | 손가락 글씨. 샤워를 틀어야 김이 생김. 몇 초 후 사라짐 |
| 전등 | 전 구역 | 깜빡임. 모스부호, 혹은 "그 사람 머리 위 전등"을 깜빡 |
| 가족사진 액자 | 거실 | **손님 단체사진.** 특정 인물 사진을 기울이거나 떨어뜨림 |
| 피아노 | 거실 | 건반 = 음. 숫자·신호로 활용 |
| 위자보드 | 다락 | 빠른 글자 입력. 대신 다락에 있으면 모두가 봄 |
| 타자기 | 서재 | 한 글자당 에너지 많이 소모. 종이로 남음 (증거물) |
| 개 | 산장 전역 | **개는 유령을 봄.** 유령이 따라다니면 개가 그 사람에게 짖음 |

### 5-3. 유령이 아는 것 (부분 정보)
- 죽는 순간 **단서 한 조각**만 본다: 레인코트 색, 신발, 반지, 향수 냄새 등.
  → 유령도 범인을 확실히 모름. 유령끼리 단서를 맞춰 추리해야 함.
- 유령 시야에서 산 자는 **흐릿한 오라**로 보임. 변장한 살인마는 구분 불가.
- 디스코드 등 외부 음성으로 몰래 알려주는 꼼수의 효과를 줄이는 장치.

## 6. 살인마의 대응: "누가 쓴 메시지인가?"

이 게임 추리의 중심. 모든 메시지는 **진짜일 수도, 위조일 수도 있다.**

| 도구 | 효과 |
|---|---|
| 메시지 조작 | 자석·거울·타자기 메시지를 몰래 고쳐 써서 **다른 사람에게 누명** |
| 소금선 | 문지방에 뿌리면 유령 통과 불가 (일정 시간) |
| 거울 덮기 | 천으로 거울 봉인 |
| 퓨즈 내리기 | 구역 전등 전체 소등 → 전등 소통 차단 + 어둠 속 범행 |
| 개 간식 | 개를 잠시 다른 데로 유인 |
| 냉기 감지 | 유령이 물건을 만지면 주변이 차가워짐 → 살인마가 "유령 활동" 위치를 앎 |

산 자 입장: "자석에 BOB이라고 써 있다 → 근데 아까 부엌에 Alice가 혼자 있었는데?"

## 7. 한 판 흐름 (예시 6인, 12분)

1. **0~2분 저녁 식사:** 모두 함께. 역할 비공개 배정. 파티 대화.
2. **2분 정전:** 발전기 고장 → 흩어져서 작업.
3. **첫 살인 (~4분):** 피해자는 단서 한 조각을 보고 유령이 됨.
4. **시체 발견:** 비명 → 모두 집결 → 서로 알리바이 추궁.
5. **유령 활동:** 부엌 자석 "R E D", 거실 사진 쿵. 살인마는 몰래 "R E D"를 "B E D"로…
6. **추리·체포:** 의심 인물을 끌고 가서 와인 저장고에 감금.
7. **새벽 (12분):** 경찰 도착 → 결과 공개 + **"사후 리플레이"**: 실제 범행 장면과 위조된 메시지 장면을 보여줌.

## 8. 클립 장면 (스트리머가 찍어 갈 순간)

- 유령이 필사적으로 B-O-B를 만드는 중, 옆에 서 있던 Bob이 슬쩍 B를 발로 참.
- 거울에 "IT'S ME"라고 썼는데 아무도 욕실에 안 옴.
- 개가 계속 한 사람에게 짖는데 그 사람이 "개가 날 좋아하나 봐ㅎㅎ".
- 무고한 친구를 4명이 끌고 가서 저장고에 가둠 → 유령들이 전등을 미친 듯이 깜빡임.
- 사후 리플레이에서 "그 메시지 범인이 쓴 거였어?!"

## 9. 왜 될 것인가

1. **장르 최대 불만을 정반대로 뒤집음.** 일찍 죽어도 할 게 많고, 오히려 더 재밌는 역할.
2. **진짜/위조 메시지 구조**가 매판 다른 추리를 만듦 → 반복 플레이.
3. **말 못 하는 유령 vs 말 많은 산 자** → 자연스러운 코미디.
4. 프렌드슬롭 공식(친구, 싸게, 물리, 근접 음성)에 그대로 맞음.
